"# XamSaMed

## Application progressive (PWA)

Le site peut être installé comme application depuis un navigateur compatible. Il doit être servi depuis HTTPS (ou `localhost`) : ouvrir les fichiers directement avec `file://` ne permet pas l’installation ni le mode hors ligne.

Pour lancer un serveur local avec Python :

```sh
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000/mobile.html` et choisir **Installer l’application** dans le menu du navigateur. Après le premier chargement en ligne, les pages et ressources principales restent disponibles hors ligne. Les polices distantes et la vidéo de la page Sources nécessitent toujours une connexion."
